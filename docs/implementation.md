# 本地独立复现方案与验收

目标：复用已采集的公开客户端，使其界面、Box2D 物理、教程、游戏模式、地图/皮肤编辑器和回放逻辑在本地运行；实现客户端协议兼容的独立服务端。默认仅监听本机，不发布公网，不连接官方账号或写入官方服务。

实现范围：

- 客户端资源镜像、去广告、同源 API/Socket.IO/PeerJS 适配。
- 房间列表、建房/加入/密码、聊天、玩家/队伍/房主、开局/回大厅。
- 原客户端输入、管理员事件、地图设置、晚加入状态和回滚同步。
- 新的本地账号、头像/按键、好友、地图/收藏/搜索和回放持久化。
- 本地 PeerJS signaling 与真实浏览器 P2P DataConnection。

原服数据库、账号凭据、社区地图全集及未公开服务端实现没有取得，不能声称逐字节或历史数据完全一致。兼容后端按客户端可见协议重建。

验收：

1. 独立资源加载，断开官方服务后菜单和教程仍运行。
2. 两个真实浏览器客户端建房/加入/聊天/开局，输入在双方呈现；真实 P2P 建连。
3. 房主/密码/输入字段等服务端边界验证，不允许非房主执行治理操作。
4. 本地账号注册登录、地图保存搜索、所有权拒绝、服务重启保留。
5. 原版编辑器/皮肤/回放相关可见流程检查；未覆盖功能如实列出。

实施并行范围：资源镜像、协议契约调查、持久化 API 独立推进，主 Agent 负责实时服务、适配与整体验证。
